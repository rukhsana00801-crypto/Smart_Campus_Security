# Smart Campus Security & Access Management

## About the Project
Smart Campus Security & Access Management is a system designed to improve campus safety and manage access within educational institutions. It helps monitor campus entry and exit activities while providing a secure and organized environment for students, staff, and administration.

## Key Features
- Secure Login & Authentication
- Student and Staff Management
- Role-Based Access Control
- Entry and Exit Monitoring
- Campus Security Management
- Access Permission Management

## Objectives
- Improve overall campus security.
- Prevent unauthorized access.
- Maintain organized access records.
- Make campus access management easier and more efficient.

## Project Goal
To develop a smart and reliable campus security solution that makes access management easier, safer, and more efficient.
